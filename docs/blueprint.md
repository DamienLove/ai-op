# **App Name**: Remote AI Assistant

## Core Features:

- LLM Connection: Connect to a Large Language Model API (such as OpenAI or Gemini) to receive and process instructions.
- Command Execution: Use the LLM as a tool to decide which command to execute based on the user's request. The LLM needs to determine if a command needs to be executed at all, or if it can respond to the user without executing a command.
- Secure Interface: Provide a secure interface to display LLM responses and log executed commands.

## Style Guidelines:

- Primary color: Dark gray (#333) for a professional look.
- Secondary color: Light gray (#f0f0f0) for content areas.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clean and modern font for code display and AI responses.
- Split screen layout with command input/output on one side and AI response on the other.
- Simple, clear icons for actions like connect, disconnect, and execute.
